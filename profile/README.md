# MAP-Tele: Communication Networks (2026/2027) 📡

Welcome to the official GitHub organization for the **Communication Networks** course of the MAP-Tele Doctoral Program – 2026/2027 edition.

This organization centralizes the development, agile management, and review of code and documentation for the PhD students' individual research projects.

> **Instructor:** Prof. Vinicius Ferreira (University of Minho)
> 
> **Course Focus:** Research, Simulation, Emulation, and Performance Evaluation of Networks (SDN, FANETs, IoT, NTN, etc.).

---

## 🎯 Organization Goals

At the PhD level, the project is not just an academic assignment, but a concrete step toward a scientific contributions. Using this organization allows us to:

1. **Agile Management:** Track research progress using *GitHub Projects* (Kanban).
2. **Code and Text Review:** Use *Pull Requests* (PRs) and *Issues* to get direct feedback on simulation scripts (C++/Python) or LaTeX manuscripts.
3. **Scientific Reproducibility:** Ensure that code, generated datasets, and results are well-structured and safely stored.

---

## ⚙️ How Our Workflow Operates

Each student will have their own space and autonomy and as an Instructor I will guide and help managing the projects.

### 1. Private Repositories
Each student will have access to a private repository managed within this organization (e.g., `fanets-project-john` or `5g-ntn-project-mary`). Only the student and the instructor will have access to this repository.

### 2. Management with GitHub Projects (Kanban)
We will use the organization's Kanban board to track the semester
